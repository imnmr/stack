Algorithm (pseudocode)

▸ How Palindrome Detection Works
  • Each character is pushed onto the stack left to right.
  • The stack reverses the order — popping gives the string backwards.
  • We then pop each character and compare it with the original at the same index.
  • If every pair matches, the string is a palindrome. One mismatch is enough to reject it.

… … [r,a,c,e,c,a,r]
pop r vs r ✓ match [r,a,c,e,c,a]
…all match ✓ [] palindrome!

Algorithm (pseudocode)

▸ How Bracket Matching Works
  • Opening brackets ( [ { are pushed.
  • Each closing bracket triggers a pop and a type check.
  • A mismatch (e.g. [(])) is an error.
  • A closing bracket on an empty stack means no matching opener.
  • If the stack is empty after scanning, all brackets are balanced.

Undo / Redo Editor

Idle

Two stacks power undo/redo. Every edit pushes a snapshot onto the undo stack. Undo pops it and pushes to the redo stack. Redo reverses the flow.

Snapshots on Space, Enter, punctuation, or after a short pause — just like a real editor.

Shortcuts: Ctrl+Z undo · Ctrl+Y / Ctrl+Shift+Z redo

Algorithm (pseudocode)

▸ How Undo / Redo Works
  • Every meaningful edit pushes a snapshot onto the undo stack.
  • Undo: pop from undo → push to redo → restore that state.
  • Redo: pop from redo → push to undo → restore that state.
  • A new edit clears the redo stack (you branched off a new path).

type "he" ["", "he"] []
type "hello" ["","he","hello"] []

Undo [""] ["hello","he"]
Redo ["","he"] ["hello"]
new edit ["","he","hey"] [] cleared!
