    ▸ How Postfix Works
    • Operands (numbers) are pushed onto the stack.
    • Operators pop their operands from the stack.
    • The operation is performed on those operands.
    • The result is pushed back onto the stack.
    • The stack is LIFO: the last value pushed is the first one popped.
    • The first value popped is the right operand, so 5 2 − means 5 − 2.

      ▸ How the Shunting Yard Algorithm Works
      • Numbers go straight to the output queue.
      • Operators first pop any stack operators that must run earlier (higher precedence, or equal precedence when the new operator is left-associative), then are pushed.
      • “(” is pushed; it blocks popping.
      • “)” pops operators to the output until “(” is found, then discards both parentheses.
      • At the end of the input, all remaining operators are popped to the output.
      • A leftover or missing parenthesis means the expression is mismatched.
      • The output is the postfix expression: evaluate it in the calculator tab.
